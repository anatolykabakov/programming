# Детальная информация о ZMQ сообщениях

## 🎯 Новая функциональность

ZMQ Reader теперь публикует детальную информацию о каждом полученном сообщении, включая топик, размер, время и статистику.

## 📊 Публикуемые данные

### 1. Информация о сообщениях (messageInfo)
Для каждого полученного сообщения публикуется JSON с детальной информацией:

```json
{
  "topic": "wideRoadCameraBuffer",
  "size": 1234567,
  "timestamp": 1695123456789,
  "count": 42,
  "rate": 15.5
}
```

**Поля:**
- `topic` - название топика
- `size` - размер сообщения в байтах
- `timestamp` - время получения в миллисекундах (Unix timestamp)
- `count` - общее количество сообщений по этому топику
- `rate` - средняя скорость сообщений в секунду

### 2. Счетчики сообщений (messageCounters)
Агрегированная статистика по всем топикам:

```json
{
  "counters": {
    "wideRoadCameraState": 15,
    "wideRoadCameraBuffer": 42,
    "gpsData": 8,
    "imuData": 156
  },
  "timestamp": 1695123456789
}
```

## 🔧 Технические детали

### Новые методы в ZMQReader:

1. **`publishMessageInfo()`** - публикует детальную информацию о каждом сообщении
2. **Обновленный `processMessage()`** - теперь получает данные как строку и публикует информацию
3. **Переменная `startTime_`** - для расчета скорости сообщений

### Топики для подписки:

- **`messageInfo`** - детальная информация о каждом сообщении
- **`messageCounters`** - агрегированные счетчики

## 🚀 Использование

### Мониторинг информации о сообщениях:
```bash
python3 test_message_info.py info
```

### Мониторинг счетчиков:
```bash
python3 test_message_info.py counters
```

### Пример вывода:
```
📊 Message Info:
   Topic: wideRoadCameraBuffer
   Size: 1234567 bytes
   Time: 14:30:15.123
   Count: 42
   Rate: 15.50 msg/sec
----------------------------------------
```

## 📈 Преимущества

1. **Детальная диагностика** - полная информация о каждом сообщении
2. **Мониторинг производительности** - скорость и размеры сообщений
3. **Отладка** - легкое отслеживание проблем с передачей данных
4. **Статистика** - агрегированные данные по всем топикам
5. **Временные метки** - точное время получения сообщений

## 🔍 Мониторинг

Используйте предоставленные скрипты для мониторинга:

- `test_message_info.py` - основной скрипт мониторинга
- `monitor_logs.py` - мониторинг логов на устройстве

## 📱 Интеграция

ZMQReader автоматически публикует эту информацию при работе с ZMQ топиками. Никаких дополнительных настроек не требуется.
