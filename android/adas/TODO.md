## 2. 📡 ZMQ и Передача Данных

### 2.1 Оптимизация логирования через ZMQLogger 🔴

**Проблема:** Передача IMU/GPS/Camera по сети неэффективна для логирования

**Решение:**
- [ ] ZMQLogger должен логировать IMU, GPS, Camera **напрямую в Android**
  - Прямая запись в файл без передачи по ZMQ
  - Снижение нагрузки на сеть
  - Уменьшение latency

- [ ] Одометрию логировать через ZMQ
  - Одометрия вычисляется в adas_app (C++)
  - Передается через ZMQ для логирования
  - ZMQLogger записывает в odom.txt

**Архитектура:**
```
Android (Java)                    C++ (adas_app)
├── IMUHandler      ──┐
├── GPSHandler      ──┼──> Direct Write ──> logs/
├── CameraHandler   ──┘
│
└── ZMQLogger       <──── ZMQ ────┤
                                  └─ Odometry (computed)
```

**Зависимости:** Выполнить после 2.2

### 2.2 Флаг для передачи сенсоров через ZMQ 🔴

**Цель:** Сделать передачу IMU/GPS/Camera по ZMQ опциональной

**Задачи:**
- [ ] Добавить флаг в adas_app: `--enable-sensor-zmq`
- [ ] По умолчанию: IMU/GPS/Camera НЕ передаются через ZMQ
- [ ] С флагом: IMU/GPS/Camera передаются (для отладки, визуализации в реальном времени)

**Конфигурация:**
```cpp
// config.h
struct AdasConfig {
    bool enable_sensor_zmq = false;  // default: disabled
    bool enable_odometry_zmq = true; // default: enabled
};
```

**Использование:**
```bash
# Обычный режим (только логирование)
./adas_app

# Отладка (с передачей по ZMQ)
./adas_app --enable-sensor-zmq
```
