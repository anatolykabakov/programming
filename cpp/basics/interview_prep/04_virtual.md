# 04. Виртуальность и наследование

## Что спросят

**Как работает виртуальный вызов.** В объекте лежит указатель на таблицу виртуальных
функций класса. Вызов идёт косвенно через неё, поэтому платишь `+8` байт к размеру
объекта и косвенным переходом.

    sizeof(Lidar) без virtual      = 4
    sizeof(LidarVirtual) с virtual = 16   (vptr + int + выравнивание)

**Виртуальный деструктор.** Обязателен, если объект удаляют через указатель на базу.
Иначе вызовется только деструктор базы, а часть наследника не разрушится.
`~vector`, `~unique_ptr` и все неявные деструкторы — `noexcept`.

**Slicing.** Присваивание объекта наследника в объект базы **по значению** отрезает
наследную часть: копируются только поля базы, виртуальность теряется. Лечится работой
через ссылку или указатель.

**Виртуальный вызов из конструктора или деструктора.** Разрешается в реализацию
**базы**: во время конструирования базы наследника ещё нет, во время её разрушения —
уже нет. Чисто виртуальный метод в этот момент → `pure virtual method called` и
`terminate`.

**Многопоточный вариант того же.** Поток, запущенный в конструкторе базы, дёргает
виртуальный метод параллельно с обновлением указателя на таблицу:

    183 вызова ушли в Base::tick, 17 в Derived::tick
    WARNING: ThreadSanitizer: data race on vptr (ctor/dtor vs virtual call)

Правило: `this` отдавать в поток только из отдельного `start()` после полного
построения объекта; останавливать поток — в деструкторе самого производного класса.

**Когда `virtual` не нужен.** Если тип известен на этапе компиляции — CRTP: база
задаёт каркас, наследник подставляет шаги, вызовы инлайнятся, vptr нет. Цена — нет
общего базового типа, поэтому `vector<Base*>` невозможен; для разнородной коллекции
берут `std::variant` с `std::visit`.

**Касты.** `static_cast` — проверяется компилятором; `dynamic_cast` — вниз по иерархии
с проверкой в рантайме, требует RTTI и полиморфного типа, возвращает `nullptr` для
указателей и бросает для ссылок; `const_cast` — снять `const` (запись через него в
исходно константный объект — UB); `reinterpret_cast` — «считай эти байты другим типом».
