## Твои слабые места

Это то, что реально прозвучало неверно за наши сессии — проговорить вслух:

1. **Определение race condition** совпадало с определением data race. Разные вещи:
   одно про память и UB, другое про логику и планировщик.
2. **Потокобезопасность `shared_ptr`**: копирование одного указателя из двух потоков —
   не гонка, атомарен только счётчик.
3. **Предикат и семантика `wait`**: предикат — условие продолжения; мьютекс отпускается
   на время сна и захватывается заново перед проверкой.
4. **Диагноз гарантии исключений**: коду с двойным освобождением была поставлена basic,
   хотя гарантия равна минимуму по путям.
5. **Сложность до кода** — не названа ни разу в четырнадцати задачах.

## Как проверять себя

```bash
g++ -std=c++17 -g -Wall -Wextra -Wshadow -Wconversion \
    -fsanitize=address,undefined task.cpp -o t && ./t

# многопоточное — отдельно:
g++ -std=c++17 -g -pthread -fsanitize=thread task.cpp -o t_tsan
setarch $(uname -m) -R ./t_tsan     # setarch нужен из-за ASLR на этом ядре
```

Ноль варнингов и молчание санитайзеров — часть задания, а не бонус.

Все числа в файлах — из прогонов на GCC 11.4, libstdc++, x86-64.
